# App de Prestadores de Serviço (MVP)

Projeto de estudo desenvolvido com Flask + SQLite.

## Funcionalidades

- Cadastro (Cliente e Prestador)
- Login
- Feed de prestadores
- Busca por localização
- Agendamento de serviços
- Contatos (mini agenda)
- Perfil do usuário
